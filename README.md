# 📖 Dyslexia-Friendly Reader

A web-based reading platform designed to help people with dyslexia read digital text more comfortably, efficiently, and with reduced cognitive stress.

---

## 🌟 Project Overview

The **Dyslexia-Friendly Reader** is an accessibility-focused web application that improves the readability of digital content for users with dyslexia.

Many dyslexic users face challenges such as:
- Crowded paragraphs
- Poor spacing
- Complex vocabulary
- Visual stress while reading

This project solves these issues by providing:
- Better text formatting
- Simplified vocabulary
- Adjustable reading settings
- Personalized reading history

The platform creates a clean, user-friendly, and customizable reading environment that enhances comprehension and reduces reading difficulty.

---

## ❗ Problem Statement

People with dyslexia often struggle to read standard digital text because most websites and reading platforms are not designed with accessibility in mind.

Common problems include:
- Poor text spacing
- Difficult vocabulary
- Dense paragraphs
- Lack of personalization
- Increased cognitive load

The project aims to build a dyslexia-friendly platform that improves accessibility, readability, and user comfort while reading digital content.

---

## 🎯 Objectives

The main objectives of the project are:

1. Create a user-friendly platform for dyslexic readers.
2. Improve readability using spacing and formatting techniques.
3. Simplify difficult words into easier alternatives.
4. Provide customizable reading settings.
5. Maintain personalized reading history.
6. Reduce reading stress and improve comprehension.

## ✨ Features

### 🔐 User Authentication
- Signup and Login system
- Session handling using LocalStorage
- Logout functionality

### 📖 Dyslexia-Friendly Reading
- Splits large text into smaller readable sections
- Highlights separated sentences
- Adjustable line spacing

### 🧠 Text Simplification
- Replaces difficult words with simpler alternatives
- Improves readability and understanding

### 📊 Difficulty Checker
Analyzes text difficulty level and displays:
- Easy
- Medium
- Hard

### ⚙️ Custom Settings
Users can customize:
- Font size
- Letter spacing
- Line spacing
- Background color

### 📜 Reading History
- Saves previously entered text
- User-specific history storage
- Delete individual history entries
- Clear all history

### 👤 Personalized Experience
- Displays logged-in username
- Separate history for each user

## 🏗️ Architecture / Workflow

### Step 1: User Authentication
- User signs up or logs in
- Credentials stored using LocalStorage

### Step 2: Session Management
- Application checks login status
- User session is maintained

### Step 3: Text Input
- User enters or pastes text

### Step 4: Text Processing
The system:
- Splits large text into readable chunks
- Simplifies difficult words
- Applies dyslexia-friendly formatting

### Step 5: Difficulty Analysis
- Text difficulty is analyzed
- Difficulty level is displayed

### Step 6: Save History
- Text is stored in personalized reading history

### Step 7: Settings Customization
Users can adjust:
- Font size
- Letter spacing
- Line spacing
- Background color

### Step 8: Output Display
- Processed text is displayed in an easier-to-read format
